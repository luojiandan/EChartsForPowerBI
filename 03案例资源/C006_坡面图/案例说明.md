 

# C006_坡面图

## 案例简介

坡面图是一种融合**规模对比、增减额和增长率**的组合可视化图表。

传统做法通常需要多个柱状图或多个 Grid，分别展示同期规模、本期规模、同比增减额及同比增长率。而坡面图通过两个数据端点、一条连接线和一块填充面积，将这些信息整合到同一个坐标系中。

**用最少的布局空间，呈现尽可能丰富的数据变化信息。**

本案例以中国五大手机品牌 2024—2025 年出货量为例，让用户能够同时观察各品牌的市场规模、变化方向、增减数量和增长速度。

## 核心技术原理

基于 ECharts 的 `custom` 自定义系列，在单个 `grid` 中组合绘制多种视觉元素：

1. **双期规模**：通过两个数据端点及数值标签，分别展示同期和本期规模。
2. **变化趋势**：连接两个端点形成倾斜线段，直观表达增长或下降方向。
3. **面积填充**：以零基线为参照，填充连接线下方区域，增强规模与变化的视觉感知。
4. **增减额与增长率**：通过数据计算动态生成变化指标，使用绿色和红色区分增长与下降。
5. **富文本交互**：使用 `tooltip.formatter`，在鼠标悬停时集中展示完整的对比信息。

数据采用「年份、类别、数值」三列的通用长表结构，自动识别两个对比周期并计算变化指标，无需针对具体年份修改绘图逻辑。

## 适用场景

适用于需要在有限空间内，同时比较多个对象的**规模与变化**的业务场景，例如：

- **销售分析**：比较不同产品或区域的销售额、销售增量及增长率。
- **市场分析**：比较不同品牌的销量、市场规模及同比表现。
- **经营分析**：比较不同部门的收入、利润或业务量变化。
- **运营分析**：比较不同平台的用户规模、用户增长量及增长率。
- **行业分析**：比较不同地区或行业的产量、交易量及年度变化。

建议用于 **两个对比周期、5～7 个类别**的数据分析场景，以兼顾信息密度和阅读体验。

**案例价值：一个 Grid，四项指标，让规模与变化一目了然。**

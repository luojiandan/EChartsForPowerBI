# C009_双时期连接散点图

## 案例简介

本案例使用 **ECharts for Power BI**，以 2024—2025 年中国大陆 31 个省级地区的居民人均可支配收入与消费支出为示例，展示同一对象在两个时期的变化。

- **横轴**：人均消费支出；**纵轴**：人均可支配收入，单位均为元/人·年。
- **灰色散点**表示较早时期，**彩色散点**表示较晚时期；连接线展示同一地区的变化方向与幅度。
- **绿色**表示纵轴指标增速不低于横轴指标，**红色**表示纵轴指标增速低于横轴指标。颜色仅表示增速比较结果，不直接代表经济状况好坏。
- **收支平衡虚线**表示 `y = x`（收入等于支出）。坐标轴可以使用独立数值范围，因此虚线不一定呈现 45° 角。

图表标题：**中国31省，2025年收入和消费谁增长得更快？**

视频名称：**Power BI 看31省居民收支变化：钱赚得快，还是花得快？｜ECharts for Power BI 案例C006**

> 数据说明：目前示例数据尚未完成全部省份、两个年度各指标与官方原始统计表的逐项复核；正式发布视频或案例数据前仍需完成最终核验。

## 核心技术原理

1. **四字段通用输入**：原始数据使用四列：**年度、省份、收入、支出**。其中“省份”是通用类别字段，可替换为城市、产品等对象名称。代码以四个平行一维数组接收数据，按“年度 + 对象”配对，不将具体年份写死在变量名里，默认选择最新两个时期，也可通过参数指定。
2. **连接散点绘制**：分别绘制两期散点，使用 ECharts `custom series` 的 `renderItem` 连接对应对象的两个坐标位置；对越界线段进行裁剪。
3. **自动计算与配色**：分别计算两项指标从早期到晚期的同比增长率，以两项增速之差确定连接线和当前散点颜色；Tooltip 将结果转成“哪项增长更快、相差多少个百分点”的直观表述。若较早时期指标值为零，则相应增长率不可计算。
4. **缩放交互与动态标注**：支持鼠标滚轮缩放、拖拽平移、双击恢复全景；根据当前缩放级别增加可显示的对象标签，配合避让策略降低密集区域的文字重叠。
5. **统一视觉表达**：标题、网格、配色、标签、坐标轴、Tooltip、数据来源及说明均集中在顶部 `CONFIG` 中调整；Tooltip 使用白底、浅边框、深色文字，并以 `▲`、`▼` 区分指标增减。

## 适用场景

- **区域比较**：不同省份或城市的居民收入与消费、经济规模与投入变化。
- **经营分析**：产品或门店的收入与成本、销售额与费用、订单量与客单价变化。
- **贸易与财务**：不同经济体进出口、部门收入与支出等双指标对比。
- **时间演变**：对比两个季度、年度或其他时期，识别对象的移动方向、变化幅度及增速差异。
- **交互探索**：适合在 Power BI 仪表板中通过缩放与平移查看密集对象的细节，也可录制操作过程用于短视频讲解。

> 适用前提：两个指标应有明确、可解释的比较关系；只有当 X、Y 指标量纲与统计口径可直接比较时，`y = x` 才能作为有实际含义的平衡线。否则应关闭该参考线或重新定义参考标准。

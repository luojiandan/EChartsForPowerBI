## 一、案例简介

本案例使用 **ECharts for Power BI** 制作交互式多维平行坐标图，将同一对象的五项不同量纲指标连接成一条折线。它重点解决：**当分析对象较多、需要同时观察多个指标并组合筛选时，如何不依赖多张独立图表完成探索？**

**示例主题：** 越富裕，就一定越长寿吗？——2023 年 30 个经济体的五维发展指标对比。

图表从左到右显示 **人均 GDP、互联网使用率、城镇人口占比、总和生育率、预期寿命**。预期寿命作为核心观察指标放在最右侧。每根纵轴使用自己的数值刻度，不把不同单位强行共用尺度。

- **浅蓝灰色折线：** 全部经济体的背景轨迹。
- **红色折线：** 当前通过搜索框或点击方式锁定的对象；颜色表示“当前选中”，**不代表指标改善或恶化**。
- **红色节点与数值：** 在五根坐标轴的真实对应位置标注被选中对象的五项数值，减少对照刻度的负担。
- **搜索与下拉选择：** 可输入中文名称实时匹配，也可以展开带滚动条的列表选择经济体；取消选中后恢复常规展示。
- **坐标轴范围刷选：** 可在多根指标轴上分别划定范围，对符合组合条件的对象进行交互探索。

**数据来源与统计范围：** 世界银行（World Bank）World Development Indicators（WDI），使用 Gapminder / Open Numbers 公布的 WDI 数据镜像中 **2023 年**数据。案例从候选经济体中选取 **30 个五项指标均完整**的示例，不代表全球所有国家或地区，更不能据此进行全球排名或推断总体分布。没有为凑齐样本而进行插值或人为补值。

原始数据及查询入口：

- 数据镜像：<https://github.com/open-numbers/ddf--open_numbers--world_development_indicators>
- 世界银行 WDI：<https://databank.worldbank.org/source/world-development-indicators>

**五项指标定义：**

| 指标 | WDI 指标代码 | 单位与含义 |
|---|---|---|
| 人均 GDP | `NY.GDP.PCAP.CD` | 现价美元/人；受名义汇率和价格水平影响，非购买力平价指标 |
| 互联网使用率 | `IT.NET.USER.ZS` | 使用互联网人口占比，% |
| 城镇人口占比 | `SP.URB.TOTL.IN.ZS` | 城镇人口占总人口比例，% |
| 总和生育率 | `SP.DYN.TFRT.IN` | 孩/女性；根据某时期各年龄别生育率推算的平均每名女性终身生育子女数，并非实际跟踪一生的生育结果 |
| 预期寿命 | `SP.DYN.LE00.IN` | 出生时预期寿命，岁；是时期生命表统计指标 |

在当前样本中，例如印度尼西亚的五项原始数值分别约为 **4,876 美元、69.2%、58.1%、2.13 孩/女性、71.1 岁**（界面按设定精度显示）。该示例仅用于说明读图方法，不应将五维轨迹理解为因果链。

## 二、核心技术原理

### 1. 六个原始数据字段：一个名称、五个指标

JS 输入区使用 **六个平行的一维数组**：`对象名称`、`指标1`、`指标2`、`指标3`、`指标4`、`指标5`。同一下标代表同一对象，原始字段不使用对象数组。对应的 CSV 也只有六列；**2023 年是这一份静态样本共同的统计年份，不是需要逐行录入的第七个字段**。

在 ECharts for Power BI 中，可按实际绑定顺序替换成 `dataArr.dataObjects[i].values`。注意：示例数组顺序为**人均 GDP → 预期寿命 → 互联网使用率 → 城镇人口占比 → 总和生育率**；屏幕坐标轴通过 `setting.axisDisplayOrder` 改为**人均 GDP → 互联网使用率 → 城镇人口占比 → 总和生育率 → 预期寿命**。**展示顺序的变化不代表原始字段顺序变化。**

模板校验数组长度、空值、非有限数值、重复对象名称和轴值范围，避免错误数据被悄悄绘制。默认至少需要两个对象、两个数值指标；具体轴数由指标数组与 `setting.axisDefs` 配置共同决定。五维是本例配置，并非必须固定为五轴。

### 2. ECharts `parallel` 多维坐标系

使用 `parallel` 组织坐标空间、`parallelAxis` 配置各指标轴、`series.type = 'parallel'` 将每个对象绘制成多维折线。五项指标单位不同，每根轴依据实际输入值和合理留白单独设置刻度；百分比指标限制在 0—100 范围，不为美观改变真实数据。

重点说明：**平行坐标折线连接的是不同指标，不是按时间变化的折线图**。同一条线的上升或下降，不能直接理解为经营增长、改善或恶化。

### 3. 搜索、锁定高亮和下拉列表

右上角搜索框支持点击展开、滚动查看全部经济体、中文输入实时过滤、方向键/回车选择及清空。选中后相应折线以红色突出，其余轨迹淡化；再次点击相同折线可取消锁定。输入词匹配多个对象时允许同时突出匹配项；只有唯一明确对象时显示对应节点数值。

搜索框在 **JS 内部通过 ECharts 容器创建轻量 DOM 输入控件**，无外部 HTML 或 CSS 文件。实际部署须确认 ECharts for Power BI 所处宿主环境允许 DOM 输入、焦点和滚动事件。搜索框与原生 Power BI 筛选器不是同一种机制。

### 4. 轴上数值标签与富文本 Tooltip

选定单个经济体后，图表按其真实轴坐标，在每根指标轴上放置圆形节点及数值文本。数值标注直接靠近折线与坐标轴交点，不再绘制独立的底部详情卡。单位写在坐标轴标题中，节点处只写必要小数位。选中状态切换时，图形使用稳定 ID 更新/隐藏，避免反复删除未创建的 `graphic` 元素。

白底富文本 Tooltip 显示对象名称及五项完整指标，并对**总和生育率**补充定义：它由某时期的年龄别生育率推算，属于时期指标，**不能解释为实际对同一批女性终生跟踪得到的平均值**。说明由 `setting.axisDefs[].description` 控制，替换业务指标后可删除或更换解释，不需改 Tooltip 算法。

### 5. 坐标轴范围刷选与应用边界

ECharts 的 `parallelAxis` 支持通过拖拽选择范围，多轴条件可用于交互探索。用户可调节 `setting` 中的标题、来源、指标名称、单位、小数位、轴顺序、颜色、标签开关、搜索框宽度及其他样式参数。

- **刷选、高亮、搜索都只作用于当前 ECharts 图形**，不等同于 Power BI 原生跨视觉对象交叉筛选；要实现跨视觉对象联动需另行开发和验收。
- 不同指标轴的刻度独立，折线斜率并不代表不同指标之间的数值变化量；不应直接比较不同轴的线段高度差。
- 单年横截面数据只能展示同年指标关联及对象差异，**不能证明人均 GDP 导致预期寿命变化**，亦不能据此判断长期因果机制。
- 30 个经济体为精选展示样本，不具备统计随机抽样性质，不应当作世界所有经济体的代表。
- 若更换指标，需同步更新 `setting.axisDefs` 中的名称、单位、边界、小数位和指标解释，以及标题、副标题、数据来源；不可沿用示例的 2023 年描述。
- 如果宿主环境限制输入控件注入，可能影响内嵌搜索框，需在目标 Power BI 环境实际测试。

## 三、适用场景

**1. 国家与地区多指标比较。** 综合浏览经济、健康、人口和数字化指标，发现不同经济体的发展特征与异常组合，适合教育、研究及公共数据演示。

**2. 企业供应商评估。** 将交付及时率、质量合格率、价格、碳排放等放在不同指标轴上，筛选满足多条件的供应商；应根据业务含义明确各指标的正负方向。

**3. 门店与渠道管理。** 在门店数量较多时，同时观察客流、客单价、复购率、利润率等，借助搜索和轴上刷选探索不同经营群体。

**4. 产品与客户分群。** 对产品生命周期、使用频率、客单价、满意度等多指标进行探索，可配合其他报表做后续细分，但不要把图内刷选误当作跨报表过滤。

**5. ECharts for Power BI 技术展示。** 综合演示原生平行坐标轴、可输入与可滚动搜索、折线点击锁定、多轴刷选、轴上动态数值标注、富文本 Tooltip 和通用参数配置。

**案例价值定位：** 技术优势不是单纯的五根轴，而是把**多指标比较、主动定位、直接标注和组合筛选**整合在一张可复用的图表中。

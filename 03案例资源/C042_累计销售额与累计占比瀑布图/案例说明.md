##  一、案例简介

本案例使用 **ECharts for Power BI** 与 ECharts `custom series`，参照横向“金额与份额 + 累计瀑布”的双区域图式，制作**横向占比与累计瀑布组合图**。左侧用渐变水平柱、金额和百分比表示单个类别贡献；右侧用顺序衔接的悬浮矩形显示新增贡献，同时标注累计金额及累计占比。两侧按类别行严格对齐，适合在同一个画面中读出“谁贡献最多”和“累计到第几类达到某个阈值”。

演示选用**猫眼专业版 2025 年度电影票房排行榜前18部影片**的公开数据，原始数据单位为**万元**，案例除以 10,000 换算为**亿元**。18部影片票房合计 **387.6143 亿元**（图中显示 **387.61亿元**），前7部累计 **310.2523亿元**，占这18部影片合计的 **80.04%**（图中显示 **80.0%**）。

**统计口径：** 全图的“份额”和“累计占比”均以**入选TOP18影片合计票房**为分母，不是2025年全国电影总票房份额。图中 `TOP18合计` 不能读成全国年度总票房；这些金额是截至所采用榜单数据的统计值，若网站后续更新，演示代码不会自动同步。

**数据来源：** [猫眼专业版《2025年票房排行榜》](https://piaofang.maoyan.com/rankings/year?year=2025)（排名和各片票房，单位万元）。

视觉采用白底、深灰文字、Apple 风格蓝色渐变，弱化分隔线和辅助坐标。颜色用于辨识数据块与先后位置，不表示影片质量、口碑或正负绩效。

## 二、核心技术原理

1. **两个平行的一维数组。** 原始输入只有 `类别` 与 `数值` 两个字段；同一索引对应同一条记录，数值单位由 `setting.unit` 标明，当前示例为亿元。需要在 Power BI 中接入真实数据时，按实际字段顺序替换为 `dataArr.dataObjects[i].values`，无需另行提供份额或累计列。
2. **排序及派生指标。** 根据 `setting.sortDescending` 可按金额降序；程序逐行计算 `总额 = Σ金额`、`类别份额 = 本类别金额 / 总额`、`累计金额 = 前若干类别金额之和`、`累计份额 = 累计金额 / 总额`，保证同一个分母与一致的排序。数据必须是非空、非负且有限的数值，合计必须大于零。
3. **双区域图形布局。** ECharts 一个自适应 `grid` 配合**两个 `custom series`**：左侧 `renderItem` 绘制类目、单片金额、渐变条、百分比；右侧 `renderItem` 计算 `累计前值` 到 `累计现值` 的横向起止坐标，绘制悬浮增量块，并标注累计金额及累计占比。此处“瀑布”指**逐项累加的浮动区间条**，不是常见的帕累托累计折线。
4. **响应式宽度。** V2 起由每次图表重绘时的 `api.getWidth()` 和 `params.coordSys` 重新求出左右区域起点、间隔、比例和柱宽；图表容器发生 `resize()` 后，两侧会共同收缩而保持行对齐。为保证可读性，窄屏按宽度简化分类名称、数字位数及栏头。在宿主中仍需由 Power BI 视觉对象正确触发 ECharts `resize()`。
5. **富文本 Tooltip。** 悬浮时显示当前类别的同色标记、排名、单项金额、单项占比、截至本项的累计金额和累计占比；同时明确写出 `TOP18合计` 分母。表内展示通常保留两位金额小数和一位占比小数，实际计算基于输入数据完整精度完成，避免逐项舍入引入累计误差。
6. **可配置与适用边界。** `setting` 集中维护标题、副标题、单位、蓝色配色、布局比例、间距、金额小数位等可调参数。底部两行保留来源及口径。当前模板适合**正数构成的金额、数量和频数**；有负值、重复计算或不可累加的比率时，不能直接沿用相同累计算法。图形在极窄容器中会降低标签密度，建议使用**宽度至少约 700px** 的容器展示全部数值列；约500px时宜依赖 Tooltip 查看完整类目。

**Power BI 输入示例：**

```javascript
// 以下索引只是示例，实际以字段槽位对应顺序为准。
var 类别 = dataArr.dataObjects[0].values;
var 数值 = dataArr.dataObjects[1].values;
```

## 三、适用场景

- **产品销售贡献：** 商品、品牌、SKU 的销售额及对所选产品集合的累计贡献。
- **客户价值分析：** 客户订单额、收入或利润贡献，识别头部客户与80%阈值（需明确利润数据是否包含负值）。
- **渠道与区域经营：** 分析渠道/区域销售份额和累计结构，便于识别集中风险。
- **成本与费用分布：** 按正向费用金额由高到低排序，找出消耗资源最多的几个费用项。
- **内容与媒体表现：** 影片票房、视频播放量、文章阅读量等可加总指标的头部集中度分析。

**读图方法：** 先看左侧单项柱长与百分比，按从大到小寻找头部类别；再观察右侧逐行累计增长，找到累计占比第一次达到 80%（或业务设定阈值）的类别行。必须检查分析分母是“当前筛选集合的合计”，还是“全部总体”，两者结论不同。

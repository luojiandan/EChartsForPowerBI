## 一、案例简介

本案例面向 **ECharts for Power BI**，以中国民航真实航线数据制作**交互式地理 OD（Origin–Destination，起终点）飞线图**。利用简洁的中国省级轮廓、机场散点、带方向的曲线与可选流动光点，展示“航线从哪里出发、抵达哪里、规模有多大”；选中目标后在标题下方固定显示关键指标，并在悬停时提供富文本 Tooltip。

演示数据来自**中国民用航空局《2024年全国民航航班运行效率报告》表9**，包括 **20 条单向航线、7 座机场、合计 214,466 班航班**。其中，上海虹桥 → 深圳宝安为示例中班次最多的单向航线，共 **13,949 班**。数据时间范围为 **2024 年**；代码不会自动联网更新数据。

**官方数据来源：** [中国民用航空局《2024年全国民航航班运行效率报告》](https://www.caac.gov.cn/XXGK/XXGK/ZFGW/202505/t20250528_227622.html)（表9，班次、同比、平均实际飞行距离）。

**核心口径：**

- 航班班次**不是旅客人数**，也不是机场总吞吐量。
- 图中排名、比例、机场相关班次均按**当前展示的航线样本**计算；当 `topN` 或 Power BI 筛选数据变化时，分母、排名及机场汇总会同步变化。示例总数 214,466 班是20条单向记录之和，不代表全国所有国内航线总班次。
- 机场关联班次按当前样本的**出发班次 + 到达班次**计算；同一航班对其出发和到达机场各计一次，不能跨机场简单加总为独立航班总数。
- 弧线代表机场间的示意连接与方向，**不是真实航迹**，曲率用于提高往返航线可辨识性。

## 二、核心技术原理

1. **九个平行的一维数组。** 原始输入采用 `出发机场`、`到达机场`、`航班班次`、`班次同比`、`平均飞行距离`、`出发经度`、`出发纬度`、`到达经度`、`到达纬度` 九个数组；第 `i` 个索引代表同一条单向航线。CSV 以相同字段名和数值逐项导出，共20条。同比数据以**百分点形式输入**，例如 `-4.11` 表示下降 4.11%，不是 `-0.0411`。飞行距离单位为公里，源代码按对应配置显示。
2. **动态构造节点与线路。** 程序先校验数组长度、班次数值及经纬度，再按班次降序排列，并依 `setting.topN` 截取航线；根据出发、到达节点名称和坐标生成机场集合、节点尺寸、关联航线数与出发/到达班次汇总。当前样本比例按 `单条班次 ÷ 当前展示航线班次合计` 计算，不需要用户另传占比。
3. **ECharts `geo` + `lines` + `scatter`。** `geo` 显示地图及可缩放、可拖动的地理坐标系；第一层 `lines` 表示真实班次对应的有向飞线，线宽按当前班次范围映射；第二层 `lines` 以 `effect` 显示运动光点；`scatter` 绘制节点和名称。往返两向航线通过一致的曲率规则和坐标反转形成可区分的弧线，飞行光点与对应线使用相同曲率。
4. **流动动画可配置。** `showMovingDots: true` 控制是否播放动画；`animateTopN: 7` 表示**未选中时按班次排序只给前7条航线播放动画**，而非只绘制7条；改为 `20` 可使20条均播放，`0` 可关闭默认状态下的动画。选中机场或航线后，与当前选择关联的航线成为动画对象。`topN` 控制展示样本条数，与 `animateTopN` 不同。
5. **点击聚焦与固定详情栏。** 点击一条航线，高亮目标及起终点，标题下方显示其**排名、班次、当前样本占比、同比、平均飞行距离**；点击机场时显示其**关联航线条数、关联班次、样本占比、出发/到达班次**。点击其他目标直接切换，点击地图空白区域清除选择并恢复样本概览。悬停 Tooltip 独立用于临时预览；详情栏只由点击状态驱动。标题详情支持宽屏四列、窄屏两列，在 ECharts `resize()` 后按容器宽度重排。
6. **配置与代码复用。** `setting` 位于源码开头，集中管理标题、年份、数据来源、单位、`topN`、`animateTopN`、飞线/节点样式、详情栏和字段显示名称。代码按“输入校验→统计聚合→图形数据→详情栏布局→点击事件”分段组织，便于用 AI 定点修改。地图使用内嵌的中国省级示意 GeoJSON 派生数据，因此无需运行时请求外部地图文件；**但更换成其他国家/区域的 OD 数据时，必须同步替换底图，不会自动适配到新的国家边界**。

**Power BI 字段替换示例：**

```javascript
// 数组索引仅为示例，以实际 ECharts for Power BI 字段顺序为准。
var 出发机场 = dataArr.dataObjects[0].values;
var 到达机场 = dataArr.dataObjects[1].values;
var 航班班次 = dataArr.dataObjects[2].values;
var 班次同比 = dataArr.dataObjects[3].values;
var 平均飞行距离 = dataArr.dataObjects[4].values;
var 出发经度 = dataArr.dataObjects[5].values;
var 出发纬度 = dataArr.dataObjects[6].values;
var 到达经度 = dataArr.dataObjects[7].values;
var 到达纬度 = dataArr.dataObjects[8].values;
```

更换业务数据时，应同时检查**各字段长度、经纬度是否有效、班次/规模是否为非负数、同比百分比口径、距离单位**，并修改 `setting.title`、`year`、`metricName`、`metricUnit`、`dataSource`、`mapNote` 及节点/线路称谓。ECharts 官方编辑器通常使用 `myChart` 实例；在 ECharts for Power BI 中，宿主需要正确暴露实例并处理 `resize()`，才能完整使用点击联动与自适应详情栏。

## 三、适用场景

- **交通运输网络：** 航空航线、铁路班次、道路客货流向及核心枢纽分析；需确保输入指标与标题所称“客流、班次、货运量”等口径一致。
- **物流运输：** 仓库到目的地的订单数、运输批次、物流吨位与配送距离；通过节点与线路选中定位重点物流通道。
- **区域业务流动：** 分公司—城市、销售区域—客户所在城市等跨区域连接与规模分析。
- **人口与通勤 OD：** 区域之间的迁移、出行或通勤流向；不能把轨迹示意线理解为实际通行路线。
- **跨区域服务网络：** 服务中心与分支机构、跨城市供应链与渠道网络的连接结构展示。

**读图方法：** 先看线宽和节点规模识别主要流向 → 点击机场观察与其关联的所有航线 → 点击单条飞线查看详细指标 → 点击地图空白恢复全图。若线路非常密集，优先调小 `topN` 或 `animateTopN`，保留更多信息在 Tooltip 和固定详情栏中。

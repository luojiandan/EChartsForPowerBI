## 一、案例简介

本案例使用 ECharts 桑基图（Sankey），以 **2024 年中国三类出口商品的市场流向**为演示主题，呈现“**中国 → 商品类别 → 出口市场**”三层关系。连线宽度对应出口额，悬停某条流向时，高亮关联节点和路径，让用户同时观察商品规模与目的地构成。

- **三类商品**：电气设备（HS85）、机械设备（HS84）、车辆及零部件（HS87）。
- **目的地**：美国、越南、日本、韩国、德国、亚洲其他市场、欧洲其他市场、中东市场、拉美市场、非洲市场和其他市场。
- **数据范围**：2024 年；单位统一为**亿美元**；CSV 共 **36 条流向记录、15 个唯一节点**。
- **所选三类商品总额**：**17,402.7 亿美元**（依据案例输入数据汇总，**并非中国全部出口额**）。
- **数据性质**：混合示例。保留了已验收 JS 文件对“来源数据 / 模拟数据”的逐条标记；HS84 及从“其他市场”细分出的地区流量包含模拟分配。因此，**不能将本图的地区占比或商品出口分布当作完整、独立核实的官方统计结论**。
- **来源说明**：代码引用 WITS / World Bank 的 HS85、HS87 五国数据；其他区域拆分及 HS84 采用演示数据。可在 [WITS](https://wits.worldbank.org/) 查询相关贸易数据。正式使用须以同口径官方源数据替换模拟部分。

## 二、核心技术原理

**1. 多层节点与流向关系**  
采用 ECharts `series.type = 'sankey'`，节点使用 `data`，有向连线使用 `links`，按“来源节点 → 目标节点 → 流量值”构建三层有向网络。独立节点通过名称关联，不使用固定行业逻辑，便于替换业务数据。

**2. 平行数组输入与数据预处理**  
原始代码采用 `sourceNodes[]`、`targetNodes[]`、`flowValues[]` 三个一维数组，各数组相同索引代表同一流向。`simulatedFlags[]` 用于标识是否为模拟数据；内部再转换为桑基图要求的节点和连线对象。配套 CSV 包含“年份、来源节点、目标节点、出口额_亿美元、数据性质”，适合导入 Power BI。

**3. 流量守恒与比例计算**  
每个中间节点的流入总量应等于其流出总量。本案例三类商品均已通过算术平衡校验（保留精度时差额为零或仅为浮点舍入量）。Tooltip 中的占比使用“该流向出口额 ÷ 所选三类商品总额”，**不是占中国全部出口额的比例**。

**4. 流向着色与关联高亮**  
通过节点配色、`lineStyle.color = 'source'` 区分商品来源，设置流线透明度与曲率；`emphasis.focus = 'adjacency'` 在鼠标悬停时突出关联节点与连线，降低其他路径视觉干扰。

**5. Tooltip 与布局配置**  
使用 HTML Tooltip 显示出口额和所选商品总额占比，统一使用“亿美元”；可调节点宽度、节点间距、颜色、流线透明度、版心边距等参数均集中在代码顶部 `setting`。图表标题、来源和说明由 ECharts `title` / `graphic` 实现。

## 三、使用场景

- **国际贸易分析**：国家 → 商品类别 → 目的地市场，观察出口结构和重点市场。
- **企业销售渠道**：集团 → 产品线 → 区域/渠道，追踪销售金额的去向。
- **供应链流向**：供应商 → 仓库 → 门店，展示货物流量及集中环节。
- **预算或成本分配**：资金来源 → 成本科目 → 使用部门，表达分配结构。
- **客户路径分析**：客群来源 → 渠道 → 转化结果，展示各环节流量。

**数据使用提示：** 此版本为“真实数据与模拟数据混合”的技术演示案例。用在正式经营报告时，应全部替换为可核验的真实明细，且避免来源/目标重复命名造成节点合并。需要保持中间节点流量守恒，并注意金额或数量单位的一致性。

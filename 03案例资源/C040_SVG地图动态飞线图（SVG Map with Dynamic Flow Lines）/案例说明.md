# C038_SVG地图动态飞线图（SVG Map with Dynamic Flow Lines）

## 一、案例简介

本案例使用 **ECharts for Power BI** 制作基于 **SVG 地图的动态飞线图**（SVG Map with Dynamic Flow Lines）。以广东省 SVG 地图为底图，将各城市作为流动起点、广州作为统一终点，通过弧形飞线及沿线运动的箭头展示人口流动方向；使用城市节点与涟漪效果突出地理位置，并以**暖色系连续渐变**表示各条线路对应的人口流量大小。左下角的横向颜色图例辅助比较“少—多”，鼠标悬浮于飞线或城市节点时，可查看来源城市、目的城市和人口流量。

案例的重点不是单纯展示地图动画，而是将**流向、规模和空间位置**整合到同一张图中，帮助观众识别哪些城市流向广州的人口较多、哪些较少。当前实现以广州为固定目的地；通过替换符合要求的 SVG 地图、节点坐标和业务数据，也可用于其他区域的流动关系可视化。

**数据说明：** 图表输入为城市名称、SVG 内部 X 坐标、SVG 内部 Y 坐标和人口流量（默认单位：万人）四列。当前提供的代码未附可核实的人口统计来源、实际统计年份及流量口径，标题中的“20XX”是占位文本。因此，本案例目前应视为**可视化技术与交互模板**；正式发布人口分析结论前，须核实数据来源、统计时间、流入／流出口径和单位，不能直接把演示画面视为实际人口迁移事实。

## 二、核心技术原理

1. **数据输入与 Power BI 绑定：** 使用城市名称、X 坐标、Y 坐标、人口流量四个独立的一维数组，分别对应 `dataArr.dataObjects[0]` 至 `[3]` 的 `values`。各数组按相同索引组成同一条记录；程序会跳过名称为空、坐标或数值无效的记录。人口流量作为飞线的 `value`，同时用于提示信息和颜色映射。若源数据存在同一城市的多条记录，应先在 Power BI 中按分析口径汇总，以免重复绘制。
2. **SVG 地图与坐标定位：** 通过 `JQ.get()` 异步获取广东省 SVG 文件，使用 `echarts.registerMap()` 注册地图，并在 `geo` 地理坐标系中绘制图形。城市节点使用的是**SVG 图像内部坐标，不是经纬度**；固定目的地坐标通过 `setting.destinationCoord` 指定。因此，替换 SVG 地图时必须重新匹配节点和终点坐标，不能直接沿用其他地图的坐标值。
3. **动态飞线与流动方向：** 采用 `lines` 系列连接各城市与广州，`coords: [起点坐标, 终点坐标]` 决定线路两端。通过曲率 `curveness` 形成弧线，使用 `effect` 的箭头符号、循环动画、运动周期和轨迹长度呈现流动效果。原始代码中普通线宽为 `3`，鼠标强调状态线宽为 `5`；**线宽与动画速度目前均不按人口流量变化**，人口规模主要通过颜色表达。
4. **人口规模的颜色映射：** 采用连续型 `visualMap`，将飞线对应的流量数值映射到暖橙—金黄色渐变，并将横向图例放在地图左下角，以避开主体内容。颜色范围上限可根据当前数据中的最大流量动态计算；若只希望飞线变色，可通过 `seriesIndex: 0` 限定映射对象。**动态图例表示当前数据范围内的相对大小**：当 Power BI 筛选条件或年份变化时，最大值及颜色对应关系可能改变；跨期比较需要设置统一的固定范围。正式交付还应核对图例“少—多”的方向与实际数值、飞线颜色一致。
5. **城市节点与交互提示：** 使用 `effectScatter` 绘制城市圆点和涟漪动画，节点大小保持固定。全局 `tooltip` 同时响应飞线和城市节点，通过自定义 HTML 展示“来源城市 → 广州”及人口流量；人口值支持指定小数位，城市名称经过 HTML 转义处理，提示框限制在图表区域内，避免遮挡或越界。
6. **参数化与可复用性：** 图表标题、目的地名称与坐标、单位、基础线宽、悬停线宽及 Tooltip 小数位集中在代码开头的 `setting` 中。用户更换四列 Power BI 数据即可复用相同绘制逻辑；若改为其他目的地或其他区域，则需同步调整目的地坐标、SVG 底图和对应的节点坐标。SVG 文件使用在线地址加载，运行环境必须允许访问该资源。

## 三、适用场景

- **人口流动与城市吸引力分析：** 展示不同来源城市到目标城市的人口流入规模及空间分布，辅助观察主要来源地；涉及“迁移”“通勤”“流动人口”等概念时，应先明确统计口径。
- **交通运输与客流分析：** 可视化城市间旅客流量、出行线路、航空或铁路客流，结合数量字段突出主要通道。
- **物流配送与供应链网络：** 展示仓库、物流枢纽或区域中心与目的地之间的货物流向及运输量，识别高流量线路。
- **区域业务与经营看板：** 表达客户来源、跨城市订单、销售流向或服务覆盖关系，并结合 Power BI 筛选器按业务维度查看不同线路的规模。

**使用限制：** 飞线表示数据中定义的**方向性联系和数量**，不等于真实道路、铁路线路或实际移动轨迹；SVG 内部坐标也不具备经纬度测距含义。颜色可快速区分相对规模，但精确数值应以 Tooltip 或配套数据表为准。正式用于人口研究或对外发布时，应标注数据来源、统计年份、指标定义及必要的数据处理说明。

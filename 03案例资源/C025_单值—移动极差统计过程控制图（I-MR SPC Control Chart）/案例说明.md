## 一、案例简介

本案例使用 **ECharts for Power BI** 构建单值—移动极差统计过程控制图（Individuals–Moving Range，简称 **I-MR**），将同一监测序列的观测值与相邻观测变化幅度放在上下两个坐标系中，以统计控制限及可配置规则提示值得调查的过程变化。

案例展示主题为：**液压测试台：哪些振动波动值得关注？**

- **数据来源**：Helwig、Pignanelli、Schütze（2015），*Condition monitoring of hydraulic systems*，UCI Machine Learning Repository，DOI：10.24432/C5CW21。数据集链接：<https://archive.ics.uci.edu/dataset/447/condition+monitoring+of+hydraulic+systems>。
- **取样范围**：`VS1.txt` 第 2187–2205 行，对应 19 个连续测试循环；与 `profile.txt` 相同的 19 行一一对应。
- **工况约束**：所选循环 `profile.txt` 五项标签均为 `[100, 100, 0, 90, 0]`，即在数据集定义下处于相同的已标注测试工况；其中稳定标志为 `0`，指实验测试条件稳定，并不代表已经通过 SPC 的统计稳定性检验。
- **数据处理**：每个循环包含 60 个 `VS1` 振动速度采样值（采样频率 1 Hz），按**算术平均值**汇总为一个观测值，单位 **mm/s**。最终保留 19 个循环、19 个观测值，不对实测值进行人工改动。
- **配套 CSV**：`C025_数据.csv`，仅包含 `观测序号`、`观测数值` 两列，分别与定稿 JS 中的两个示例输入数组逐项一致。`观测数值` 是原始 60 秒采样数据按循环计算的派生均值，而非单个瞬时传感器读数；保留定稿 JS 的六位小数输入精度。

上半部分 **I 单值控制图**观察测量值的变化及是否越过控制限；下半部分 **MR 移动极差控制图**观察相邻循环之间变化幅度是否异常。红色标记表示启用规则触发的统计信号，不能直接等同于设备故障或产品不合格。

## 二、核心技术原理

### 1. 数据结构与 Power BI 绑定

模板以两个平行的一维数组作为输入，相同数组索引代表同一条观测记录：

```javascript
var 观测序号 = [2187, 2188, 2189 /* ... */];
var 观测数值 = [0.547483, 0.548450, 0.546333 /* ... */];
```

在 ECharts for Power BI 中，按视觉对象**实际字段顺序**替换为 `dataArr.dataObjects[i].values`。应确保输入行是连续、可比的监测观测；若 Power BI 提前聚合、重复观测序号或改变记录粒度，则必须先修正数据。模板对数组长度、数值有效性、重复观测序号进行校验；`sortMode` 控制排序方式。日期或数值顺序应与真实过程顺序一致。

### 2. 移动极差与基线

移动极差采用相邻两次观测值的差的绝对值：

\[
MR_i = |X_i-X_{i-1}|
\]

本次定稿代码使用 `setting.baselineCount = 10`，即以第 2187–2196 个循环的 **10 条观测**估计基线，其均值为 `CL_I`，基线中 9 个相邻差的均值为 `\overline{MR}`：

\[
CL_I = \bar X, \qquad \widehat{\sigma} = \frac{\overline{MR}}{1.128}
\]

### 3. 统计控制限

单值控制图：

\[
UCL_I=\bar X + 3\widehat{\sigma},\qquad LCL_I=\bar X - 3\widehat{\sigma}
\]

移动极差控制图：

\[
CL_{MR}=\overline{MR},\qquad UCL_{MR}=3.267\,\overline{MR}
\]

上述常数适用于相邻 2 点移动极差的常见 I-MR 计算方式。计算方法参见美国 NIST《Individuals Control Charts》：<https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc322.htm>。

定稿示例以 JS 输入精度计算的控制线约为：

| 指标 | 控制限/中心线（mm/s） |
|---|---:|
| I 中心线 CL | 0.55010 |
| I 上控制限 UCL | 0.55597 |
| I 下控制限 LCL | 0.54423 |
| MR 中心线 CL | 0.00221 |
| MR 上控制限 UCL | 0.00721 |

### 4. 异常识别与交互

定稿模板提供三类可独立开启的规则：**I 单点超出上/下控制限**；**连续 8 个观测点位于中心线同侧**；**MR 超过移动极差上控制限**。规则判定在 JavaScript 中基于输入数据和基线动态完成，图形通过红色节点突出信号，并由富文本 Tooltip 给出观测值、控制线以及所触发的规则。

使用当前 19 条数据时：

- 第 **2204** 个循环：I 图观测值 `0.537017 mm/s` 低于下控制限，同时 MR 超过上控制限。
- 第 **2205** 个循环：I 图回到控制限内，但 MR 仍超过上控制限，表明相邻周期恢复变化幅度较大。
- 当前共有 **I 越界 1 个、MR 越界 2 个、连续同侧 0 个**。这些是不同规则的触发数量，不是独立设备故障次数。

### 5. 统计适用条件与限制

**本例仅用于可视化和 SPC 方法教学，不可直接作为生产报警阈值。** 前 10 条基线样本不足以充分评估过程是否稳定；正式使用时应先识别并确认具有代表性、稳定且可比的基线，检查是否存在显著自相关、周期效应、工况切换或长期漂移。基线及控制限应由业务管理人员依据真实过程确认，不应为了改变异常数量而调参。

本例将每个 60 秒循环求均值，适合展示循环间变化，但会掩盖循环内部的瞬时尖峰。**统计控制限不等于产品规格限**；超限信号意味着需要调查，不等于故障、违规或质量不合格。

## 三、适用场景

- **制造业质量与设备状态监测**：对同一设备、产线或工艺条件下的尺寸、压力、温度、振动等连续数值进行过程监测，及时发现突变和持续偏移。
- **生产效率与供应链过程管理**：监测批次生产节拍、订单处理时长、入库作业时间等可比数值指标；数据须保持稳定的采样方式和业务口径。
- **销售和经营运营**：对经过工作日、节假日、促销和季节性因素处理后可比的每日订单量、响应时间等指标识别异常变化，而不是仅依据环比涨跌作判断。
- **IT 运维与服务质量**：监测接口响应时长、任务处理耗时、服务排队时间等连续值；需要注意业务高峰和负载变化对基线的影响。

对于不良率、缺陷件数等属性型数据，应根据数据特征考虑 p、np、c、u 等相应控制图，不能直接套用本模板的 I-MR 假设。

**使用前提：** 各期观测之间应具有可比性；正式分析应确认抽样粒度、基线范围、异常规则和处置流程。ECharts for Power BI 负责提供灵活的计算与可视化表达，最终业务判断仍应结合工艺知识与现场调查。

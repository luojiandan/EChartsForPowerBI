1、图表代码.txt
  - 这个记事本中的内容，可以直接复制到ECharts官方编辑器中运行查看效果
  - 拷贝到ECharts for PowerBI中后，替换第1部分的示例数据即可
  - 官方编辑器地址：https://echarts.apache.org/examples/zh/editor.html?c=line-simple

2、该案例参考IBCS(国际商业沟通标准)视觉表达方式制作

3、在代码中，第2部分 参数设置部分，有3个参数用于设置 【指标名称、年度、分组】 的显示顺序，分别为：  
  - periods: ['2024','2025'], // 明确指定 PY、AC 年度，不依赖 Power BI 的行顺序；
  - groupOrder: ['美洲','欧洲','大中华区','日本','亚太其他地区','公司层面','集团合计'], // 分组固定顺序；其他案例可自行修改
  - indicatorOrder: ['营业收入','销售成本','营业利润','未分配营业费用及调整'], // 每个分组内指标顺序；其他案例可自行修改

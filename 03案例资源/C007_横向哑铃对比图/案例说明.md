# C007_横向哑铃对比图

## 一、案例简介

本案例采用**横向哑铃图**，在一张图表中同时呈现不同品牌的同期规模、本期规模、增减额和增长率。

以 2024—2025 年中国四家新势力车企的全年交付量为例，通过两个圆点及连接线，直观回答三个问题：**谁规模最大、谁增长最快、谁增量最多？**

相比传统分组柱状图，哑铃图减少了视觉元素，更突出两个周期之间的变化，适合在有限空间内呈现多维度对比信息。

## 二、核心技术原理

本案例基于 ECharts 的 `scatter` 和 `custom series` 实现，核心包括三个部分：

1. **双期规模对比：**使用两个散点系列，分别表示同期和本期数值。圆点在同一数值坐标轴上的位置体现规模大小。
2. **增减额与增长率：**通过 `custom series` 连接两个圆点，线段长度体现增减额的绝对值，绿色表示增长、红色表示下降；同时自动计算并标注增减额和增长率。
3. **动态数据与交互：**基于年份、品牌、交付量三个字段自动分组、汇总、计算及排序，并通过 HTML 富文本 Tooltip 展示完整的双期对比信息。

所有周期均由输入数据动态识别，不依赖固定年份，便于在 ECharts for Power BI 中复用。

## 三、适用场景

适用于需要比较**两个时间周期的规模及变化情况**的业务分析场景，例如：

- 销售分析：不同产品、品牌或地区的销售额、销量同比对比。
- 经营分析：各业务板块的收入、利润、成本变化。
- 市场分析：企业市场份额、用户规模、产品出货量变化。
- 运营分析：各渠道流量、订单量、活跃用户数变化。

尤其适合类别数量适中、需要同时关注**绝对规模、实际增减量和相对增长速度**的分析场景。

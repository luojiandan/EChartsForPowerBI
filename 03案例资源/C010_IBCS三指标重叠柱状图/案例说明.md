## 一、案例简介

本案例参考 **IBCS（国际商业沟通标准）** 的视觉表达方式，通过一张重叠柱状图，同时呈现 **PY（同期）、AC（当期实际）、PL（目标）** 三组数据，实现历史表现、当前规模与目标达成情况的直观对比。

案例采用2024—2025年零跑、小鹏、小米、理想四家新能源汽车品牌的年度交付量，展示不同企业的增长表现与目标完成情况。部分目标采用公开报道或推算的参考值，具体口径以案例数据说明为准。

与传统分组柱状图相比，重叠柱状图能够在更小的空间内呈现更多信息，让数据之间的差异更加直观。

## 二、核心技术原理

**1. 多情景重叠柱状图**

使用 ECharts `custom` 自定义系列，通过 `renderItem` 在同一坐标位置绘制不同宽度的柱体，实现三组数据的重叠展示，而非数值累加的堆叠效果。

参考 IBCS 的视觉语义，采用不同填充方式区分数据：

- **PY（同期）：** 浅灰色实心柱，表示历史参考值。
- **AC（实际）：** 深灰色实心柱，突出当前实际值。
- **PL（目标）：** 空心轮廓柱，表示目标参考值。

**2. 多指标动态计算**

基于原始数据，自动计算同比增减额、同比增长率、目标差异及目标完成率，并通过颜色与符号突出变化方向。

**3. 富文本交互与参数化配置**

通过 HTML 富文本 Tooltip，集中展示三组原始数据及衍生指标，同时补充目标统计口径。

将数据组织、图表布局、颜色、标签及比较基准等参数集中配置，支持在 ECharts for Power BI 中动态绑定字段，实现模板复用。

## 三、使用场景

本图适用于需要同时比较**历史、实际与目标**的业务分析场景，例如：

- **销售业绩分析：** 对比同期销售额、当期实际销售额与销售目标。
- **经营绩效分析：** 展示各业务部门的历史业绩、实际完成情况与预算目标。
- **生产运营分析：** 对比历史产量、实际产量与计划产量，识别生产差异。
- **市场竞争分析：** 比较不同品牌或产品的历史销量、当前销量及年度目标。
- **KPI 目标管理：** 直观识别目标达成情况，辅助经营决策。

**核心价值：用一个柱状图，同时回答“过去怎么样、现在怎么样、目标完成了吗”三个问题。**

# 中国电影票房十年沉浮（2016—2025）

**图表类型：阶梯差值对比图**

## 案例简介

2016—2025 年，中国电影市场经历了增长、疫情冲击、复苏与调整。

本案例以中国电影年度票房为基础，通过阶梯式差值对比，同时呈现**年度票房、同比增减额和同比增长率**三个指标，直观展示电影市场十年间的规模变化及波动幅度。

相比普通柱状图，该图不仅展示每年的票房规模，还通过红绿变化色块，突出相邻年份之间的差异，并结合关键事件注释，进一步解释数据变化背后的原因。

## 核心技术原理

本案例主要使用以下技术：

### 1. Custom Series：自定义系列绘制

使用 `series.type = 'custom'` 和 `renderItem` 函数，在同一个笛卡尔坐标系中绘制两种图形：

- **灰色柱体**：表示当前年度票房总量。
- **红绿差值色块**：连接上年度与当前年度的票房高度，表示同比增减额。

通过 `api.coord()` 将数据值转换为画布坐标，动态计算柱体和差值色块的绘制位置。

这种方式可以突破普通柱状图的布局限制，实现更加灵活的组合表达。

### 2. 同比指标动态计算

原始数据只包含两个一维数组：

- `years`：年份
- `boxOffice`：年度票房

通过 JavaScript 自动计算：

**同比增减额 = 本年票房 − 上年票房**

**同比增长率 = 同比增减额 ÷ 上年票房 × 100%**

其中：

- 绿色 `#239263` 表示同比增加。
- 红色 `#D9544D` 表示同比减少。
- `▲` 表示增长，`▼` 表示下降。

每个年度的顶部集中展示增长率、增减额和票房总量。

### 3. Graphic：商业事件注释

通过 ECharts 的 `graphic` 组件，绘制独立于数据系列的商业事件注释。

每条注释由**说明卡片、连接线和数据定位点**组成。

使用注释数组配置，可以指定多个年份及对应事件说明，例如：

- 2020 年：新冠疫情冲击。
- 2023 年：电影市场恢复。

注释位置根据年份索引和对应数据值计算，无需为每个事件手动编写固定的指向坐标。

### 4. Grid：动态响应式布局

图表采用像素单位定义 `grid` 边距。

通过读取图表画布宽高，动态计算注释卡片的排列数量、行数和图表顶部留白。

当画布尺寸变化时，重新计算注释布局和连接线位置，尽量避免注释卡片与柱体相互遮挡。

### 5. Rich Text：多指标标签

利用 ECharts 富文本标签，将三个指标组合成统一的顶部标注：

1. 同比增长率
2. 同比增减额
3. 年度票房

不同指标使用不同的文字颜色、字号和字重，形成清晰的信息层次。

## 案例价值

本案例的重点不只是复刻一张图表，而是展示如何通过 **自定义图形绘制、数据计算、动态布局和事件注释**，将普通时间序列数据转化为具有商业分析价值的可视化作品。

同样的方法可以扩展到营业收入、利润、销售额、用户规模等具有连续时间周期的数据分析场景。

**核心技术：** `custom series` · `renderItem` · `api.coord()` · `graphic` · `grid` · `Rich Text` · JavaScript 数据计算

**数据来源：** 国家电影局年度全国电影票房公开统计及历史公开数据整理。

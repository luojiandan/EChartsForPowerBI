# ECharts for Power BI 版本更新日志

本文档用于记录 **ECharts for Power BI** 各版本的**新增功能、功能调整、问题修复及依赖库变更**。

## 1.3.0.0

**发布日期：2026-07-12**

### 版本说明

ECharts for Power BI 第一个正式发布版本。

本版本完成视觉对象核心功能的正式发布，可在 Power BI 中使用 ECharts 配置项创建更加灵活、个性化的数据可视化图表。

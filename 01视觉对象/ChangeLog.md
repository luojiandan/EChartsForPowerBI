# ECharts for Power BI 版本更新日志

本文档用于记录 **ECharts for Power BI** 各版本的**新增功能、功能调整、问题修复及依赖库变更**。

## 1.3.0.0

**发布日期：2026-07-12**

### 版本说明

ECharts for Power BI 第一个正式发布版本。

本版本完成视觉对象核心功能的正式发布，可在 Power BI 中使用 ECharts 配置项创建更加灵活、个性化的数据可视化图表。

### 主要依赖

| 依赖库                    | 说明                                                         | 版本            |
| ------------------------- | ------------------------------------------------------------ | --------------- |
| echarts                   | 核心可视化图表库，用于绘制柱状图、折线图、饼图、地图、关系图等各类图表 | 6.1.0           |
| echarts-gl                | ECharts 的 3D 可视化扩展库，用于绘制三维柱状图、三维散点图、三维地球和三维地图等 | 2.1.0           |
| echarts-liquidfill        | ECharts 水球图扩展库，用于展示百分比、完成率、进度等液体填充效果 | 3.1.0-ec6.1.0.1 |
| echarts-stat              | 配合 ECharts 使用的统计分析与数据挖掘工具库，支持聚类、回归、直方图和数据转换等功能 | 1.2.0           |
| echarts-china-counties-js | 中国区县级行政区划地图数据包，用于加载和展示区县级地图       | 1.0.2           |
| d3                        | 数据处理与可视化基础工具库，主要用于数据筛选、分组、聚合、排序、比例尺和地理数据处理 | 5.12.0          |
| jQuery                    | JavaScript 工具库，项目中主要用于通过 AJAX 请求获取网络数据，以及简化 DOM 操作和事件处理 | 3.5.1           |

### 备注

- 本版本为第一个正式版本。
- 后续版本更新内容将在本文档中持续维护。
- 安装或升级视觉对象前，请注意查看版本说明及兼容性变化。

# ECharts for Power BI 资源中心

本仓库用于发布和维护 **ECharts for Power BI** 视觉对象相关资源，包括**视觉对象安装文件**、**使用手册**、**案例资源**、**版本更新日志**及**案例图册**。

用户可以通过本仓库获取最新版本的视觉对象、查阅使用说明、下载案例文件，并浏览已发布的可视化成果。

## 01 视觉对象

存放 **ECharts for Power BI** 视觉对象安装文件及版本更新记录。

主要内容：

- `*.pbiviz`：可导入 Power BI Desktop 的视觉对象安装文件。
- `ChangeLog.md`：记录各版本的新增功能、功能调整、问题修复及兼容性变化。

安装或升级视觉对象前，建议先查看版本更新记录。

## 02 使用手册

存放 ECharts for Power BI 的使用说明和相关技术文档，主要包括：

- 相关参数说明
- 数据组织方式配置
- Power BI 数据与 ECharts 数据的对应关系
- 交互方式说明
- 图表制作通用步骤
- 通用CV大法
- 常见问题及解决方法

使用手册会随视觉对象功能持续更新。

## 03 案例资源

按照年度存放 ECharts for Power BI 案例文件，是本仓库更新频率最高的目录。

### 目录结构

案例资源采用以下结构：

```text
03案例资源
└─ 年度
   └─ 日期_案例名称
      ├─ Power BI 案例文件
      ├─ 配套数据
      ├─ 配套图片
      ├─ 配置代码
      └─ 相关子版本
```

示例：

```text
03案例资源
└─ 2026
   └─ 20260712_流向地图
      ├─ 流向地图.pbix
      ├─ data.xlsx
      ├─ preview.png
      ├─ option.js
      └─ v1.1
         ├─ 流向地图_v1.1.pbix
         └─ 更新说明.md
```

### 命名规则

年度目录采用四位年份：

```text
2026
2027
```

案例目录采用以下命名方式：

```text
YYYYMMDD_案例名称
```

例如：

```text
20260712_流向地图
20260715_动态排名柱状图
20260718_省市下钻地图
```

日期表示案例首次发布或归档日期。

### 案例内容

每个案例目录可能包含：

- Power BI 示例文件，通常为 `.pbix`
- Excel、CSV、JSON 等配套数据
- 图片、地图及其他静态资源
- ECharts 配置代码
- 案例说明文档
- 更新后的子版本目录

并非每个案例都会包含全部文件，具体以案例实际需要为准。

### 子版本目录

当案例存在较大调整、功能扩展或兼容性更新时，可以在案例目录中新增子版本目录。

建议采用以下命名方式：

```text
v1.1
v1.2
v2.0
```

子版本目录中建议包含对应的案例文件和更新说明。

案例资源预计每 **1～3 天**更新一次，具体更新时间根据案例制作进度确定。

下载案例时，建议保留原有目录结构和文件名称，避免数据、图片或其他资源引用失效。

## 04 图册

存放 ECharts for Power BI 案例成果图册。

图册采用 PDF 格式，主要用于集中展示已经发布的案例，并作为案例资源的视觉索引。

用户可以先通过图册浏览案例效果，再根据案例名称前往 `03案例资源` 查找对应文件。

图册预计每月更新一次。

## 快速开始

1. 进入 `01视觉对象`，下载最新版本的 `.pbiviz` 文件。
2. 在 Power BI Desktop 中导入视觉对象。
3. 进入 `02使用手册`，了解视觉对象的基本使用方法。
4. 进入 `03案例资源`，下载需要学习或使用的案例。
5. 通过 `04图册` 浏览已经发布的案例成果。

## 版本与更新

建议通过以下方式关注仓库更新：

- 点击 GitHub 仓库右上角的 **Watch**，接收更新通知。
- 查看 `01视觉对象/ChangeLog.md`，了解视觉对象版本变化。
- 查看仓库提交记录，了解案例和文档更新情况。
- 下载资源时注意文件版本和更新时间。

## 使用说明

案例主要用于演示 ECharts for Power BI 的配置方法和可视化能力。

在实际项目中，请根据业务数据、字段结构、主题样式和性能要求进行调整。

遇到显示异常时，建议优先检查：

- 是否使用了案例要求的视觉对象版本
- Power BI Desktop 版本是否符合要求
- 数据字段是否完整
- 字段名称和数据类型是否正确
- 配置代码是否完整
- 配套数据、图片或地图文件是否缺失

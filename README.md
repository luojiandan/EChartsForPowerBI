# ECharts for Power BI 资源中心

本仓库用于发布和维护 **ECharts for Power BI** 视觉对象相关资源，包括视觉对象安装文件、版本更新日志、案例文件及案例图册。

通过本仓库，用户可以获取最新版本的视觉对象，学习案例实现方法，并快速浏览已经发布的可视化成果。

## 仓库目录

```text
├─ 01视觉对象
│  ├─ *.pbiviz
│  └─ ChangeLog.md
│
├─ 02案例资源
│  ├─ 2026
│  ├─ 2027
│  └─ ...
│
├─ 03图册
│  ├─ ECharts for Power BI 案例图册.pdf
│  └─ ...
│
└─ README.md
```

### 01 视觉对象

存放 **ECharts for Power BI** 视觉对象安装文件及版本更新记录。

主要内容：

- `*.pbiviz`：可导入 Power BI Desktop 的视觉对象安装文件。
- `ChangeLog.md`：记录各版本新增功能、功能调整、问题修复及兼容性变化。

建议在安装或升级视觉对象前，先查看 `ChangeLog.md`，了解版本变化及注意事项。

### 02 案例资源

按照年度存放 ECharts for Power BI 案例文件，是本仓库更新频率最高的目录。

案例内容主要包括：

- 图表配置代码
- 案例数据
- Power BI 示例文件
- 图片、地图及其他配套资源
- 案例说明文档

预计每 **1～3 天**更新一次，具体更新时间根据案例制作进度确定。

为避免案例覆盖或引用失效，建议下载时保留原有目录结构和文件名称。

### 03 图册

存放案例成果图册，用于集中展示已经发布的 ECharts for Power BI 案例。

图册采用 PDF 格式，主要作为案例索引和效果预览使用。用户可以通过图册快速查找感兴趣的图表，再根据案例名称前往 `02案例资源` 获取对应文件。

预计每月更新一次。

## 快速开始

1. 进入 `01视觉对象` 目录，下载最新版本的 `.pbiviz` 文件。
2. 在 Power BI Desktop 中选择“导入视觉对象”，导入下载的文件。
3. 进入 `02案例资源`，选择需要学习或使用的案例。
4. 参考案例中的配置、数据结构及说明，在自己的 Power BI 报表中进行调整。
5. 通过 `03图册` 快速浏览已发布案例。

## 版本与更新

建议通过以下方式关注仓库更新：

- 点击 GitHub 仓库右上角的 **Watch**，接收更新通知。
- 查看 `01视觉对象/ChangeLog.md`，了解视觉对象版本变化。
- 查看 Git 提交记录，了解案例资源的新增和调整情况。
- 下载文件时确认文件版本及更新时间，避免使用已经废弃的旧版本。

## 使用说明

案例主要用于演示 ECharts for Power BI 的配置方法和可视化能力。实际应用时，请根据业务数据、字段结构、主题样式和性能要求进行调整。

不同版本的 Power BI Desktop、ECharts for Power BI 视觉对象及案例文件之间可能存在兼容性差异。遇到显示异常时，请优先确认：

- 是否使用了最新版本的视觉对象。
- 案例所需字段是否完整。
- 字段名称和数据类型是否正确。
- 图表配置是否被完整复制。
- Power BI Desktop 版本是否符合案例要求。

## 文件命名建议

案例资源建议统一采用以下命名方式：

```text
案例编号_案例名称_版本号
```

例如：

```text
2026-001_动态排名柱状图_v1.0
2026-002_中国地图迁徙图_v1.1
```

每个案例目录建议尽量包含：

```text
├─ README.md
├─ 示例文件
├─ 数据文件
├─ 配置代码
├─ 预览图片
└─ 其他依赖资源
```
